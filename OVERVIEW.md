ZayneTheme adds five dark cosmic themes and matching WebGL and Canvas ambient backdrop scenes for Paseo.

### Themes

Select any theme under Settings > Appearance:

1. Zayne Cyber Aurora: midnight violet #06060f with terracotta #d97757 and sky ring #38bdf8.
2. Zayne Obsidian Gold: smoked obsidian #07060a with champagne gold #e5a95c and intersecting astrolabe orbits.
3. Zayne Moss Dusk: pine-ink night #040a09 with jade #5eead4, moonlight shafts, fireflies, and pond ripples.
4. Zayne Silver Singularity: deep space #050508 with silver #e5e7eb and a 3D geodesic raymarched black hole.
5. Zayne Astral Prism: midnight indigo #040811 with cyan #22d3ee, prism beams, and an interactive hexagonal lattice.

### Living Cosmos Settings and Platform Behavior

On Paseo Desktop and Web, an automatic ambient layer matches the active Zayne theme and renders softly behind panels, pausing automatically when tabs are hidden or idle. Open Settings > Plugins > ZayneTheme Cosmos or run the Command Center actions to switch or pin any scene, choose Subtle, Balanced, or Immersive intensity, toggle pointer ripples, or optionally enable system reduced-motion pausing.

Requires Paseo 0.17.4 or later. All five static color palettes apply on desktop, web, iOS, and Android; interactive WebGL and Canvas scenes run on desktop and web clients only. The plugin runs locally, saves preferences only in client storage, and sends no network traffic.
